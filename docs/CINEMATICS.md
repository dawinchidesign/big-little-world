# Кат-сцены: режиссура и раскадровка (vizavi motion)

Числа камеры живут в `src/direction.js`, текст — в `src/cinematics.js`. Здесь — замысел, отбор вариантов и правила, по которым собрана постановка.

## Единая нить

**Масштаб — это точка зрения.** Каждая сцена отвечает на вопрос пролога «как выглядит мир для тех, кто меньше нас?» движением камеры: спуск к земле, выход из капли, подъём над садом. Камера ведёт себя как маленький наблюдатель — дышит, наклоняется, не замирает, — а финальная фраза каждого плана (смысловая) приходит отдельно, после паузы, золотом и звоном.

## Общие механики

| Механика | Реализация |
|---|---|
| Непрерывная камера | Hermite-сплайн по времени через 3–4 ключа (`dx, dy, zoom, roll`). Скорость не обнуляется на ключах; после последнего ключа камера продолжает движение. Поверх — «дыхание оператора» (две медленные синусоиды) и микро-крен. |
| Переход с энергией | За 0,62 с до конца плана — разгон по вектору `exit`, слова уходят вверх с размытием, кадр слегка темнеет, звучит whoosh. Следующий план входит через вуаль (`dark`/`bloom`/`blur`) — склейка происходит в движении. |
| Глубина | Dolly-масштаб планов: при наезде ближний лист растёт быстрее дальней дымки (`scale = (zoom/zmin)^(0.6·rate)`, только ≥ 1, чтобы не открыть края). |
| DOF | Ближний (rate ≥ 0.45) и дальний (rate ≤ 0.1) планы размыты по силе `near`/`far`; средний план с героем всегда резкий. В комнате ближний план (кровать) не размывается — на нём лежит герой. |
| Motion blur | Направленный: величина по осям = экранная скорость камеры × rate слоя. Ближние листья смазываются сильнее, при торможении смаз гаснет. Смаз всего кадра — только во время переходного разгона. |
| Цвет | Виньетка во всех сценах; «пепельная» коррекция для катастрофы, холодная — для ночи. |
| Типографика | Титр собирается по буквам из размытия со сжатием трекинга, линия прочерчивается; субтитр — по словам в масках, темп ≈ скорость чтения; последняя фраза (смысл) — после вдоха, золотом, со звоном. Длина плана = 2,6 с + символы / 17 (6,5–11,5 с). |
| Музыка и SFX | Синтезированная партитура на 24 с (4 аккорда × 6 с; пэд + саб + челеста) в четырёх настроениях: hope, earth, tense, nocturne. Музыка биома приглушается до 18 %. Акценты: whoosh — уход плана, chime — смысловая фраза, bloom — белые входы (пробуждение, рождение бабочки), low — титр катастрофы. |
| Экономный режим | Амплитуды ×0,35, крен и «дыхание» выключены, нет FX и побуквенной анимации, только плавные появления. |

## Раскадровка по сценам

Для каждой сцены перечислены рассмотренные варианты; выбранный отмечен **жирным**.

### Пролог — «Один обычный день»
1. *Вопрос школьника (луг, муравей).* Наезд от капли росы · пролёт сквозь траву · боковое ведение за муравьём · перевод фокуса с листа на муравья · **кран вниз с наездом до масштаба муравья**: вопрос «каким видят мир маленькие» решается тем, что камера сама становится маленькой. Выход — вниз, в сон.
2. *Комната, дождь.* Статика с панорамой · облёт кровати · от страниц учебника · **боковой долли от окна с дождём к спящему мальчику** (вход продолжает вертикальное падение, крен гаснет). Стена слегка размыта, кровать и мальчик резкие.
3. *Пробуждение.* Открытие глаза-диафрагмы · панорама снизу вверх · резкая панорама-хлыст · **отъезд из макро на газон, где трава выше деревьев**: зум 3,6 → 1,2 с раскручиванием крена; белый bloom-вход и мерцание.
4. *Лада.* Наезд через плечо · статичный общий план · **дуга вокруг пары (сдвиг + крен)**; акцент «Добро пожаловать…» — золото и звон, музыка раскрывается.

### Пробуждение — «Под зелёным небом»
Медленный наезд на героя · ведение по тропе · **отъезд-подъём «посмотри, кто живёт рядом»: от героя к соседям** · облёт · статичный общий план.

### Цитадель — «Город под землёй»
1. **Спуск в разрез города** (кран вниз, отъезд по зуму) · полёт по туннелю · план сверху.
2. **Ведение вдоль хода за рабочими** · наезд на расплод · план с пищей.
3. Наезд на матку «на троне» (отвергнуто: противоречит тексту) · **дуга с наездом на камеру матки, крен меняет знак — «никто не ждёт команды»**.

### Долина — «Долина, которая замолчала»
Пролёт над пустыми цветами · перевод фокуса с шмеля на газон · **низкое ведение справа налево вдоль стриженого газона с наездом на шмеля** · общий план сверху.

### Катастрофа — «След большого мира»
Резкий наезд на стену · статика · **подъём по вертикали с отъездом, раскрывающим масштаб упаковки; голландский угол нарастает до −2,2°**, пепельный цвет, низкий удар под титр · облёт.

### Ночь — «Ночь, которая перестала быть тёмной»
Статика с фонарём · **плавающая траектория «как полёт бабочки» (S-образный путь с покачиванием)** · наезд на фонарь · отъезд в темноту.

### Миграция — «Дорога к убежищу»
Вид сверху на колонну · **параллельное ведение рядом с колонной, камера чуть опережает** (шаг колонны согласован с длиной плана) · встречный проход.

### Восстановление — «Сад, в котором есть место всем»
Наезд на цветок · **подъём-кран с отъездом над оживающим садом**, вспышки пыльцы, bloom-акцент · облёт.

### Финал — «Большой маленький мир»
1. **Дуга с наездом на Ладу** · статика · план через плечо.
2. **Подъём над цветами до «сада в одной капле»** (зум 1,25 → 0,62, крен уходит) · затемнение.
3. Белая вспышка камеры (было) · **bloom-вход из белого света в утреннюю комнату**, боковой долли от стола с листком.
4. **Сопровождение мальчика к окну** с божьей коровкой; звон на последней фразе.

### Метаморфоз — «До первого полёта»
1. **Макро-наезд на дышащее яйцо** · статика.
2. **Ведение рядом с гусеницей** (шаговое движение со сжатием и растяжением тела).
3. **Медленная качающаяся дуга вокруг подрагивающей куколки**.
4. **Кран вверх за взлетающей бабочкой** (взмахи крыльев), bloom-вход и звон.

## Проверка

- `npm run test:runtime` — все кат-сцены, повторы, очистка FX и слоёв (пройдено).
- Визуально в Chromium/WebGL: пролог (DOF, вход титров), комната (фокус), катастрофа (цвет, крен, акцент).
- Не проверено на слух в этой сессии: финальный микс партитуры и SFX. Звук синтезируется в браузере; громкость регулируется ползунками «Музыка» и «Эффекты».
