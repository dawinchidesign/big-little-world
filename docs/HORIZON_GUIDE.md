# Тропы за горизонтом · 1.1.0

В дополнение к исходному миру добавлены четыре независимые карты. На общей карте они отмечены золотыми ромбами 01–04. Нажмите «Показать вход», дойдите до отметки и нажмите E. Кнопка «Экспедиции» в главном меню открывает дневник новых маршрутов.

## Четыре места

| Место | Вход в исходном мире | Механика и награда |
| --- | --- | --- |
| Забытая оранжерея | Изумрудные джунгли, (1260, 620) | Оттолкнуть черепок от истока; верхний вентиль →, нижний ↓; набрать три порции росы и полить три ростка. Награда: Роса жизни. |
| Сердце старого дерева | Грибные катакомбы, (2740, 1920) | Прикатить жёлудь на каменную плиту; пройти за корневую дверь; перенести по одной три кладки в гнездо; забрать линзу. Награда: Янтарная линза. |
| Ручей тысячи отражений | Зеркальное озеро, (4420, 1510) | Собрать три куска коры; уложить их в три секции моста; освободить колесо; позвать ногохвостку на восточном берегу и сопровождать к мху на западе. Награда: Песнь ручья. |
| Сад над облаками травы | Старый сад, (4300, 2920) | Фонари 2 → 1 → 3; взять пыльцу; посетить три бутона; после восстановления всех четырёх мест установить янтарную линзу в телескоп. Награда: Свет кроны и общий финал. |

Порядок прохождения свободный. Для финала в телескопе нужны все четыре восстановленных места. Девять исходных глав не блокируют экспедиции. Их сюжетные цели сохраняются при переходах.

## Взаимодействия

- WASD / стрелки — движение; Shift — бег. С кладкой в руках герой идёт медленнее.
- E — действие с ближайшим предметом. Тяжёлое тело можно сдвинуть контактом или направленным толчком E; у разных тел различаются масса и сопротивление.
- Плита возле входа возвращает тяжёлые предметы на исходные позиции. Уже открытая корневая дверь остаётся открытой.
- Q — тихое наблюдение. Оставайтесь в пределах 170 единиц от обитателя около 2,2 секунды. Новое наблюдение появится в дневнике. Улитка, жужелица и златоглазка встречаются в нескольких местах, ногохвостка — в дупле и на ручье.
- C — сканер: подсветка интерактивных объектов, в том числе тайников. По два тайника на каждом маршруте, всего восемь.
- Пробел — прыжок с тенью и частицами приземления. Закрытые ворота и непочиненный мост остаются препятствиями.
- M — локальная карта; J — дневник экспедиций; V — полевые инструкции; Esc — пауза.
- Вход служит выходом. Прогресс сохраняется при действии и автоматически во время исследования.

На ручье секции открываются по одной, поэтому герой может продвигаться по мосту во время строительства. Ногохвостка ищет путь по доступным клеткам, проходит по построенному мосту и останавливается, если герой дальше 310 мировых единиц. Подойдите ближе, чтобы продолжить сопровождение.

## Графика

Для обновления использован встроенный ImageGen. Сохранены исходные прозрачные листы и набор описаний в `art-source/horizon-prompts.json`.

| Исходник | Ресурсы игры |
| --- | --- |
| `art-source/horizon-props.png` | 16 предметов: четыре входа, вентиль, цистерна, росток и цветок, черепок, жёлудь, плита, янтарь, колесо, мостик, фонарь и телескоп |
| `art-source/horizon-creatures.png` | Четыре обитателя × четыре кадра движения |
| `art-source/horizon-floors.png` | Четыре фона новых мест |

`npm run art:horizon` извлекает и регистрирует рисунки в два атласа 1024 × 1024 и четыре фоновых изображения. Код не заменяет рисунки геометрическими заглушками. Существующие растения используют исходную детализированную графику `*-hi.png`.

## Подключённые репозитории

| Репозиторий | Реальное применение |
| --- | --- |
| [Phaser](https://github.com/phaserjs/phaser) | Сцены, камеры, спрайты, управление, частицы и переходы |
| [Matter.js](https://github.com/liabru/matter-js) | Движок в составе Phaser: столкновения, вращение, масса и инерция тяжёлых предметов; нажимная плита, физические ворота и секции моста |
| [EasyStar.js](https://github.com/prettymuchbryce/easystarjs) | A* на навигационной сетке: спутник ищет путь к мху через открытый мост |
| [RBush](https://github.com/mourner/rbush) | Пространственный индекс интерактивных объектов и контактов с растениями |
| [GSAP](https://github.com/greensock/GSAP) | Сохранённая режиссура исходных сцен, меню и интерфейса |
| [Howler.js](https://github.com/goldfire/howler.js) | Звуки материалов, действий, вода, фон и завершение задач |
| [i18next](https://github.com/i18next/i18next) | Переключение русского, казахского и английского языков |

EasyStar.js 0.4.4 и RBush 4.0.1 добавлены как настоящие зависимости сборки. У Matter.js используется версия внутри Phaser 3.90.0, второй экземпляр движка не скачивается. Лицензии включены в `LICENSES/`.

## Проверки

```bash
npm ci
npm test
npm run build
npm run test:expeditions
npm run test:runtime
npm run test:browser
npm run test:browser-expeditions
```

Для двух браузерных команд нужен Chromium, установленный через Playwright (`npx playwright install chromium`), или путь к существующему Chromium в `CHROMIUM_PATH`.

Выполнены 36 тестов модели, полный прогон исходного сюжета и новых механик в Phaser Canvas, а также проверки Chromium WebGL: четыре карты, вход клавишей E, дневник, локальные карты, переключение языков, восстановление из сохранения, автономный HTML и движение на телефоне. Повторные входы проверяют регистрацию атласа героя после перезапуска сцены.

Сохранения v1–v6 мигрируют в v7. Отдельно сохраняются ресурсы, вентили, кладка в руках, положения тел, спутник, наблюдения, тайники и завершение экспедиций. Для переноса между сайтами или локальными файлами используйте экспорт/импорт JSON в настройках.
