# Проверка озвучки 1.2.0

Пройдены 42 автоматических теста. Декодированы все 285 MP3 (40,73 минуты суммарно на трёх языках); пустых файлов и отсечения сигнала нет. Финальная браузерная проверка озвучки и полный сюжетный прогон пройдены.

- `npm test`: тесты миграции настроек, владения текущей репликой, отмены загрузки, повтора, паузы, восстановления после ошибки и полного покрытия сценария файлами.
- `npm run test:browser-speech`: настоящее декодирование MP3 и воспроизведение Web Audio в Chromium; RU / KZ / EN, повтор кнопкой и R, пропуск, пауза при потере фокуса, возобновление, приглушение фона, сохранённое выключение речи, кеш всех MP3 и перезагрузка без сети, автономный `file://`, касание в эмуляции iPhone.
- Каждый MP3 проверяется FFmpeg на декодирование, ненулевой уровень и отсутствие отсечения. Сводка — `voice-source/quality.json`; границы и полнота совпадений слов — `voice-source/alignment.json`.
- 11 прежних браузерных проверок пройдены; сюжетный прогон сохраняет исходные главы, переправы и экспедиции.

Автоматические проверки подтверждают работу в Chromium. Прогон на реальных устройствах Safari/iOS и Firefox и отдельная редакторская проверка произношения носителями языков в этот этап не входят.

# Проверка сборки 1.0.0

## 1.0.0: настоящий браузер

Production-сборка запущена в Chromium (Playwright, WebGL через ANGLE/SwiftShader) на 1366 × 768 и 1920 × 1080, в эмуляции iPhone 13 (горизонтально), Pixel 7 (вертикально) и iPad Pro 11 с сенсорным вводом. Сценарий `npm run test:browser` воспроизводит 11 проверок:

- запуск с рендерером WebGL без ошибок и предупреждений консоли;
- пролог занимает экран, «Два взгляда» не открываются под ним;
- карта, дневник и пауза открываются и закрываются; герой движется с клавиатуры;
- повторы «Цитадели» и «Ночи» из дневника возвращают на исходный уровень;
- вход и выход из Подводного сада и Муравьиной цитадели;
- сохранение IndexedDB переживает перезагрузку, «Продолжить» возвращает в игру;
- service worker активируется, создаёт один версионированный кеш, игра перезагружается без сети;
- `PLAY_OFFLINE.html` из `file://` запускается и играется;
- телефон: сенсорные кнопки видны, джойстик двигает героя, кнопки HUD открывают панели.

Дополнительно вручную просмотрены кадры меню на трёх языках, всех девяти кат-сцен, «Двух взглядов», цитадели, подводного сада, ночи, финала и настроек на компьютере, телефоне и планшете. Найденные и исправленные ошибки перечислены в `RELEASE_NOTES.md`.

- Финальная последовательность, отдельный checkpoint и возврат в состояние перед финалом.
- Отдельный прогон того же сценария из автономного PLAY_OFFLINE.html со встроенными ресурсами.
- Просмотр отрисованных Canvas-кадров наземной и подводной сцены, проверка прозрачности атласов.
- RC3: игровые сцены используют новые атласы, дневник вырезает один портрет 128 × 96, размеры тела героя остались 16 × 11.2 мировых единицы. Проверены новые изображения под водой и в цитадели. Грунт цитадели растеризуется несколькими операциями на участок; устранены десятки тысяч копирований Canvas-материала, приводивших к исчерпанию памяти в native Canvas.
- RC4: отдельные планы пролога, ночи, восстановления, катастрофы, комнаты и цитадели. Проверены смена кадров, пропуск, повторные просмотры без изменения заданий, показ ночного/утреннего интерьера, освобождение спрайтов и отсутствие накопления обработчиков shutdown. Подводный слой переиспользуется между погружениями. Камера повторного просмотра подгружает нужную область, а после сцены возвращается обычный набор участков. Отрисованные кадры использованы для проверки композиции; они не входят в пользовательский архив.
- RC5: все три варианта новой переправы проходят настоящим перемещением внутри эпизода. Проверены столкновение с водой, пять переходов парома (три с пассажирами, два обратно), чтение IndexedDB посреди первого рейса, материалы, два укрытия, последовательный обход корней, ремонт, проход по мосту, все шесть жителей, однократная награда и последующее движение с пищей. Проверены журнал на трёх языках и восстановление каждого завершённого варианта из сохранения. Перед каждым вариантом тест устанавливает героя на северный берег; внутри пути не телепортируются.
- Инъекции ошибок: отсутствие обязательного изображения и недоступный IndexedDB. Проверены экран повторной загрузки и возможность игры с предупреждением об отсутствии сохранения.
- `npm audit --omit=dev --audit-level=moderate`: известных уязвимостей production-зависимостей не обнаружено на момент проверки. Это не полный аудит безопасности.

В наземной части сюжетного прогона герой программно устанавливается у точек заданий, после чего вызывается настоящее взаимодействие, диалоги и эффекты. Вторая глава и все камеры цитадели проходятся движением через физические коллизии. Это подтверждает автомат задания и новый подземный маршрут, но не является прохождением всей основной карты человеком без телепортации. Для троп контроллер отдельно проверяет все маршруты, а интеграционный тест проходит первую тропу реальным перемещением и прыжками.

## Предел проверки

Node-прогон подтверждает автомат заданий и физику маршрутов; браузерный прогон — WebGL, CSS-раскладку, IndexedDB, service worker и сенсорный ввод в движке Chromium. WebGL здесь программный (SwiftShader), поэтому замеры кадров не отражают реальные устройства.

## Как воспроизвести

```sh
npm ci
npm run art:build
npm test
npm run build
npm run test:runtime
node tests/runtime.mjs --offline
npm run test:recovery
npm run test:browser
npm audit --omit=dev --audit-level=moderate
```

Архив не содержит node_modules, временные снимки и внутренние журналы. Проект не опубликован автоматически: готовая статическая папка Netlify включена в релиз.
