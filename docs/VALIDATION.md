# Проверка 1.4.0

- `npm run build`: production-папка и автономный HTML собраны.
- `npm test`: 27 тестов, все успешны.
- `npm run test:runtime` и `npm run test:offline`: полный сценарий до финала успешно завершён. Дополнительно проверены зона покоя, второй указатель, нормализация диагонали, сохранение DOM подсказки, ограничение и объединение уведомлений, состояние наблюдения, смена языка карты ветров, немедленное применение уменьшения эффектов и возврат из настроек в паузу.
- Настоящий headless Chromium 153, Phaser WebGL (программный SwiftShader), production-сборка: 1440×900, 844×390 и 390×844. Новая игра, завершение пролога, карта, дневник, наблюдение, пауза/настройки, сохранение и продолжение после перезагрузки; клавиатурное перемещение на ПК. Ошибок JavaScript не зарегистрировано.
- В мобильной эмуляции проверены видимость языков главного меню, границы верхних кнопок и отсутствие пересечения карточки задания с джойстиком и кнопками действий. Просмотрены реальные браузерные снимки главного меню и игры.
- `npm run test:recovery`: корректный экран ошибки при отсутствии обязательного изображения; при запрете IndexedDB игра продолжает работать и сообщает о недоступности записи.
- Дополнительная проверка изменения окна в ходе игры: 390×844 → 844×390 → 568×320 → 320×568 → 1440×900. Проверены заполнение доступной площади с пропорциями 16:9, центрирование canvas и отсутствие пересечения задания, джойстика и кнопок действий.
- Изменение формата сохранений не требовалось. Ресурсы, геометрия мира, размеры платформ и сценарные цели 1.3 сохранены.

## Ограничения

Эмуляция телефона не заменяет проверку физического сенсорного экрана. SwiftShader не подтверждает производительность мобильного GPU. Звук не прослушивался; Safari, Firefox, физические iOS/Android, fullscreen и установка PWA не проверены. Автоматический сюжетный прогон переносит героя к большинству наземных целей, затем выполняет настоящие взаимодействия; это не ручное непрерывное прохождение всей карты.

Ниже сохранён исторический протокол ранней сборки, включая её тогдашние ограничения.

Грунт цитадели растеризуется несколькими операциями на участок; устранены десятки тысяч копирований Canvas-материала, приводивших к исчерпанию памяти в native Canvas.
- RC4: отдельные планы пролога, ночи, восстановления, катастрофы, комнаты и цитадели. Проверены смена кадров, пропуск, повторные просмотры без изменения заданий, показ ночного/утреннего интерьера, освобождение спрайтов и отсутствие накопления обработчиков shutdown. Подводный слой переиспользуется между погружениями. Камера повторного просмотра подгружает нужную область, а после сцены возвращается обычный набор участков. Отрисованные кадры использованы для проверки композиции; они не входят в пользовательский архив.
- Инъекции ошибок: отсутствие обязательного изображения и недоступный IndexedDB. Проверены экран повторной загрузки и возможность игры с предупреждением об отсутствии сохранения.
- `npm audit --omit=dev --audit-level=moderate`: известных уязвимостей production-зависимостей не обнаружено на момент проверки. Это не полный аудит безопасности.

В наземной части сюжетного прогона герой программно устанавливается у точек заданий, после чего вызывается настоящее взаимодействие, диалоги и эффекты. Вторая глава и все камеры цитадели проходятся движением через физические коллизии. Это подтверждает автомат задания и новый подземный маршрут, но не является прохождением всей основной карты человеком без телепортации. Для троп контроллер отдельно проверяет все маршруты, а интеграционный тест проходит первую тропу реальным перемещением и прыжками.

## Предел проверки

Управляемый настоящий браузер в текущем окружении недоступен. Прогоны выполнены в Node с DOM-эмуляцией; это не подтверждает работу WebGL, CSS-layout, реального аудио, полноэкранного режима, установки PWA и сенсорного ввода на Safari/Chrome. Проверка на реальных ПК, iPad/iPhone и Android остаётся необходимой перед публикацией для учеников.

## Как воспроизвести

```sh
npm ci
npm run art:build
npm test
npm run build
npm run test:runtime
node tests/runtime.mjs --offline
npm run test:recovery
npm audit --omit=dev --audit-level=moderate
```

Архив не содержит node_modules, временные снимки и внутренние журналы. Проект не опубликован автоматически: готовая статическая папка Netlify включена в релиз.

## Приёмочный gate перед публичным релизом

- Chrome, Firefox и Safari: новая игра → все главы → финал → возврат → закрытие/повторное открытие браузера.
- iPhone/iPad и Android: два указателя, смена ориентации, уход в фон, длинные субтитры, повторные погружения и отсутствие застреваний на маршруте.
- Реальные WebGL и Canvas: свет/смешивание, читаемость героя, отсутствие ошибок консоли и замеры кадров/памяти на слабом устройстве.
- Звук после пользовательского жеста, отдельные регуляторы, возврат из фона и блокировщики autoplay.
- HTTPS-кеш/PWA, обновление версии, запрет хранения, экспорт/импорт и загрузка старого JSON.
- Полный редакторский и методический просмотр русской, казахской и английской версий.

Эти пункты **не отмечены выполненными**. Пока gate не закрыт, маркировка остаётся RC.
