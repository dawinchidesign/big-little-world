# Озвучка ElevenLabs

`script.json` содержит исходные тексты, соответствие игровым событиям, роли и языки RU / KZ / EN. Повторяющиеся реплики используют один файл. `production.json` хранит выбранные голоса и идентификаторы генераций, `alignment.json` — границы нарезки и долю совпавших слов. Фактическое покрытие каждой локализации записано в `public/voice/index.json`.

Три роли: рассказчик, Лада и герой. Голоса выбраны из каталога ElevenLabs; записи созданы моделью `eleven_v3`. При игре воспроизводятся готовые MP3. Подключение к ElevenLabs и ключ API для игры не нужны.

## Обновление реплик

Для нарезки нужны Python 3, FFmpeg и ffprobe.

1. Изменить текст в соответствующем модуле игры и выполнить `npm run voice:script`.
2. Записать изменённый пакет в ElevenLabs. Не запускать повторную генерацию, пока предыдущая не завершилась. Для рабочего дубля достаточно одного варианта.
3. Получить тайминги Scribe для выбранного аудио. Аудио и тайминги должны относиться к одному дублю. Сохранить их как `tmp/voice/<pack>.mp3` и `tmp/voice/<pack>.words.json` с массивом `words`.
4. Выполнить `python scripts/build-voice-clips.py`. Скрипт сопоставит слова с текстом, откажется от неуверенных совпадений и создаст отдельные файлы с монофоническим звуком 44,1 кГц / 64 кбит/с, нормализацией −18 LUFS и пределом −1,5 dBTP. Проверить `alignment.json` и выполнить `npm run voice:audit` для декодирования всех файлов.
5. Выполнить `npm run build`, затем `npm run test:browser-speech` с установленным Chromium. Сборщик включает MP3 в кеш PWA и автономный HTML.

Подписанные ссылки на загрузку и данные авторизации не входят в комплект. Сырые длинные дубли и варианты остаются в проекте ElevenLabs; в игру включены только нарезанные записи.
