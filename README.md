# Большой маленький мир · Үлкен кішкентай әлем · The Great Little World

**1.4.0 · Полировка управления и интерфейса.** Сюжетное приключение на Phaser 3 с непрерывной картой, девятью главами, Муравьиной цитаделью, высотными тропами и подводным уровнем. Обновлены мобильная раскладка, джойстик, состояния режимов, уведомления, меню и подтверждение сохранений. Растения плавно открывают обзор на героя. Иллюстрированные спрайты 1.3 и совместимость сохранений сохранены. Изменения — в `docs/RELEASE_NOTES.md`.

## Быстрый запуск

В комплекте релиза откройте **PLAY_OFFLINE.html** в современном браузере. Все изображения, шрифты, код и синтезируемые звуки встроены; скачивать библиотеки не требуется. На телефоне удобнее открыть опубликованную версию. Для стабильных сохранений рекомендуется запуск через HTTP/HTTPS: поведение IndexedDB у локальных HTML-файлов зависит от браузера.

Для Netlify загрузите содержимое папки **Netlify**: `index.html` должен находиться в корне публикации. Ничего устанавливать для готовой сборки не нужно. После первого полного открытия опубликованная игра кешируется для повторного запуска без сети.

## Управление

- WASD / стрелки — движение; Shift — бег.
- Пробел — прыжок; после второй главы раскрывается листовой планер. Под водой — рывок.
- E — ближайший объект или разговор. Золотой огонёк ведёт к текущей цели.
- E у высокого стебля со светящейся меткой у основания — начать подъём. W/↑ и S/↓ — вверх/вниз; Пробел — отпустить стебель. На сенсорном экране используйте вертикальное движение джойстика и кнопку прыжка.
- Q — тихий режим наблюдения. Новые обитатели попадают в дневник при встрече.
- C — экологический сканер после Цветочной долины.
- V — «Два взгляда на один мир»: тот же объект и тот же мир при смене масштаба.
- J — дневник; M — карта; Esc — пауза; F — полный экран.
- На сенсорном устройстве: левый джойстик, кнопки действия, наблюдения и прыжка.

Язык меняется без перезапуска: Қазақша / Русский / English. Переведены диалоги, задания, карточки, меню, финал и подводная глава. В паузе можно отдохнуть до утра, сохранить прогресс или открыть настройки. Музыка, окружение и эффекты регулируются отдельно.

## Подводный сад

Войдите с северо-западного берега Зеркального озера: ищите большой голубой знак-каплю и подсказку «Нырнуть в подводный мир». Это дополнительный самостоятельный уровень, доступный при свободном исследовании. Выполните три действия: освободите проходы, понаблюдайте за тремя разными видами, восстановите растения. Светлая капля у точки входа возвращает на берег.

## Мир и история

Муравьиная цитадель теперь представляет отдельную подземную сцену. Вход находится рядом с местом, куда вы привели разведчика в конце первой главы. Во второй главе огонёк и карта показывают этот вход; веточки, ремонт перехода и наблюдение за расплодом проходят под землёй. Внутри семь камер: входной зал, пища, расплод, переплетение ходов, сухое убежище, камера матки и дальний карман с остатками.

24 рабочих следуют по доступным ходам, несут пищу и расплод, встречаются усиками и делают остановки. Часть рабочих ухаживает за расплодом на месте, часть после ремонта переносит его в убежище. Наблюдение Q записывается, когда рядом работают няньки. Светлые метки дают семь записей в разделе дневника «Жизнь колонии». Карта внутри показывает подземные ходы; зелёная метка возвращает на поверхность. Через выход можно уйти и вернуться с сохранением этапа ремонта и положения.

Изумрудные джунгли → Муравьиная цитадель → Цветочная долина → Зеркальное озеро → Грибные катакомбы → Пустошь пластика → Ядовитые поля → Ночной сад → Старый сад. На основной карте девять областей, подводный сад находится под озером.

Есть девять сюжетных заданий с несколькими этапами, дополнительное подводное задание, четыре тайны и 26 карточек обитателей. Варианты решений меняют пять игровых индексов среды. Построенные переходы, укрытия, восстановленные растения и затенённые фонари сохраняются.

Три высотные тропы находятся в Изумрудных джунглях, Цветочной долине и Ночном саду. Здесь можно карабкаться, прыгать между листьями и записывать редкие наблюдения. На последнем листе Цветочной долины открывается движковая сцена полного превращения бабочки: яйцо → гусеница → куколка → взрослое насекомое. Время в этой сцене художественно ускорено.

В четырёх ключевых местах «Два взгляда» автоматически показывает, как лес трав превращается в газон, озеро — в лужу, стена — в упаковку, сияние — в фонарь. Повторный просмотр доступен в дневнике. Это изменение масштаба одной сцены, без подмены её другой картинкой.

Кат-сцены проигрываются в движке с камерой и анимированными объектами. После финала с пробуждением и надписью «Продолжение следует…» можно загрузить сохранение перед финалом.

## Надёжность и статус релиза

Сохранения проверяются до записи; предыдущая корректная версия хранится отдельно и используется при повреждении основного слота. Старые сохранения v1–v3 мигрируют в формат v4. Сохраняются активная сцена, подземные координаты и записи камер, высота, занятый лист, положение на стебле и редкие наблюдения. При запрете IndexedDB можно играть без сохранений; игра предупреждает об этом. Рекомендуется периодически экспортировать JSON через настройки, особенно перед очисткой данных браузера.

Устранены залипание сенсорного ввода при открытии панелей, рассинхронизация камеры на высоте и гонки сна/пробуждения сцен. Проверены повторные погружения, продолжение под водой, финальный checkpoint и аварийная загрузка ресурсов. Длинные диалоги прокручиваются, панели поддерживают клавиатурный фокус, учтены безопасные зоны экрана. При системной настройке уменьшения движения изначально включается экономный режим эффектов. Для телефона рекомендуется горизонтальный экран.

В дополнение к полному Canvas-прогону выполнена проверка Chromium с WebGL и эмуляцией двух мобильных размеров: новая игра, меню, клавиатура, карта, дневник, настройки, запись и продолжение после перезагрузки. Физические iOS/Android, Safari, Firefox, фактическое качество звука, fullscreen и установка PWA отдельно не проверены. Подробный протокол — `docs/VALIDATION.md`.

Масштаб исходного master prompt ещё не исчерпан: поведение обитателей остаётся компактным автоматом состояний. Высота реализована авторскими платформами над плоскостью Arcade Physics, а цитадель — отдельной картой камер и ходов в разрезе; универсальной 3D-геометрии нет. Музыка и окружение синтезируются, диалоги даны субтитрами. Художественная детализация и вариативность эпизодов требуют дальнейшего развития.

Диалоги животных, воздушный купол героя под водой, светящиеся грибы и быстрое восстановление — художественные условности. Индексы среды не являются реальными измерениями. Разложение, загрязнение, опыление и восстановление в природе требуют времени; сбор мусора не устраняет все химические загрязнения.

## Разработка из исходников

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run art:build
npm run dev
npm test
npm run build
npm run test:runtime
npm run test:offline
npm run test:recovery
```

`npm run build` создаёт `dist/`, версионированный service worker и `release/PLAY_OFFLINE.html`. Runtime-проверка работает в Node с JSDOM и native Canvas; это не проверка в настоящем браузере.

Подробности архитектуры, проверки, источники и репозитории — в `docs/`. Лицензии зависимостей и шрифтов — в `LICENSES/`.
